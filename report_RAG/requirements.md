# 月結單處理系統 - 需求規格書

## 1. 項目概述
建立一個自動化系統，用於讀取PDF格式月結單檔案，將其內容提取並整理為markdown格式，存儲到資料庫，並提供統計分析功能。

---

## 2. 系統架構

### 2.1 主要模組

| 模組 | 功能 | 輸入 | 輸出 |
|------|------|------|------|
| **PDF讀取模組** | 解析PDF月結單檔案 | PDF檔案 | 結構化數據 |
| **數據處理模組** | 清理、驗證、轉換數據 | 結構化數據 | 規範化數據 |
| **Markdown生成模組** | 將數據轉換為markdown格式 | 規範化數據 | Markdown檔案 |
| **資料庫模組** | 數據存儲與管理 | 規範化數據 | 數據庫記錄 |
| **統計分析模組** | 數據分析與報表生成 | 資料庫數據 | 統計報告/圖表 |

---

## 3. 功能需求

### 3.1 PDF讀取與提取
- **功能1.1**: 支持批量讀取PDF檔案
- **功能1.2**: 識別月結單中的關鍵信息（日期、金額、項目名稱等）
- **功能1.3**: 提取表格數據保留結構
- **功能1.4**: 處理多頁PDF文檔
- **功能1.5**: 錯誤處理：處理損壞或格式不規範的PDF

### 3.2 數據處理
- **功能2.1**: 數據驗證（檢查必填字段、數據類型）
- **功能2.2**: 數據清理（去除多餘空格、統一日期格式等）
- **功能2.3**: 重複數據檢測與去重
- **功能2.4**: 金額計算驗證
- **功能2.5**: 異常值檢測與標記

### 3.3 Markdown生成
- **功能3.1**: 生成格式規範的markdown檔案
- **功能3.2**: 包含月份、金額、項目清單等內容
- **功能3.3**: 生成對應的元數據（處理日期、來源檔案等）
- **功能3.4**: 支持自定義样式和模板

### 3.4 資料庫操作
- **功能4.1**: 設計清晰的数据库結構（表、字段）
- **功能4.2**: 插入月結單數據
- **功能4.3**: 更新現有記錄
- **功能4.4**: 刪除過期數據
- **功能4.5**: 數據索引配置（提升查詢效能）
- **功能4.6**: 事務管理（確保數據一致性）

### 3.5 統計分析
- **功能5.1**: 按月份統計支出/收入
- **功能5.2**: 按項目/類別統計
- **功能5.3**: 時間序列分析（趨勢變化）
- **功能5.4**: 對比分析（月度/年度對比）
- **功能5.5**: 生成統計報告（表格/圖表格式）
- **功能5.6**: 數據導出功能（CSV、JSON、PDF等）

## 5. 技術棧選擇

### 5.1 PDF處理
- **候選方案**: PyPDF2, pdfplumber, pdfrw
- **推薦**: pdfplumber（表格識別能力強）

### 5.2 編程語言
- **推薦**: Python（生態完整，處理數據方便）

### 5.3 資料庫
- **候選方案**: PostgreSQL, MySQL, SQLite, MongoDB
- **推薦**: PostgreSQL（穩定性好、功能強大）或 SQLite（輕量級）

### 5.4 數據分析與可視化
- **推薦**: Pandas（數據處理）, Matplotlib/Plotly（可視化）

### 5.5 文檔生成
- **推薦**: Python-markdown, Jinja2（模板引擎）

## 6. 工作流程

```
PDF文件
  ↓
[PDF讀取模組] → 提取數據
  ↓
[數據處理模組] → 清理、驗證
  ↓
[Markdown生成] → 輸出.md檔案
  ↓
[資料庫模組] → 存儲數據
  ↓
[統計分析模組] → 生成報告
```

## 7. 數據庫設計概要

### 7.1 核心表結構

**月結單表 (monthly_reports)**
```
- id (主鍵)
- file_name (source, 來源檔案名)
- report_date (月份日期)
- total_amount (總金額)
- currency (幣種)
- item_count (項目數量)
- created_at (創建時間)
- updated_at (更新時間)
- md_file_path (markdown檔案路徑)
```

**項目明細表 (report_items)**
```
- id (主鍵)
- report_id (外鍵，關聯月結單)
- item_name (項目名稱)
- amount (金額)
- category (類別)
- description (描述)
- item_date (項目日期)
```

**統計表 (statistics)**
```
- id (主鍵)
- year_month (年月)
- total_income (總收入)
- total_expense (總支出)
- balance (結余)
- statistics_date (統計生成日期)
```

## 10. 風險評估與應對

| 風險 | 影響 | 概率 | 應對措施 |
|------|------|------|---------|
| PDF格式多樣，難以通用識別 | 高 | 中 | 使用高級PDF庫，建立格式模板 |

| 數據一致性問題 | 高 | 低 | 事務管理，數據驗證 |
| 系統故障導致數據丟失 | 很高 | 低 | 定期備份，恢復機制 |
